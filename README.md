# The Communications Revolution, 1775–2020

HamSCI-style posters recreating the tri-fold exhibit *The Communications Revolution* by
**Charlie Cebula, AC2ZU**. Over three boards, the exhibit traces how people have communicated,
from Revolutionary War pamphlets, signal flags, drums and pigeons, through the telegraph,
telephone, radio, radar and television, to the transistor, satellites, the internet, smartphones
and social media.

The original boards may have been lost, so this repository rebuilds them from photographs.

## Layout

- `source_photos/`: the original photos of the three boards, the source of record.
- `transcription/`: a word-for-word Markdown transcription of every panel, errors included.
  Each file ends with transcriber notes that list unclear readings and suggested corrections.
- `posters/`: poster sources and built PDFs, using the HamSCI poster template from
  [`HamSCI/presentation_templates`](https://github.com/HamSCI/presentation_templates).
